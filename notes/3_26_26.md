## Different Types of Systems
- Expert System = Human is the expert that defines the domain, input feature space, feature engineering. 
    - Human decides on the input feature space, the rule, and then apply the rule
    - In goes data and a program --> computer --> output
- Machine Learning System = Instead of setting arbitrary thresholds, feed it examples and the data to come up with rules, features, and all that.
    - In goes data and output --> computer --> program

- Within the learned systems, there's supervised and unsupervised approaches
    - Supervised = Have data and ground truth to get output
        - SAT IMG --> training data --> classification --> classified map
    - Unsupervised = Have data and you want it to come up with its own groupings without ground truth
        - SAT IMG --> clustering --> classification

## Notes from last week / assignment
- Stratified Sampling 
    - Dividing data into meaningful strata
        - Existing LULC
        - Ecozones / biomes
        - Population density
        - Administrative boundaries
    - Determining sample sizes
        - Proportional to strata area
        - Oversample rare classes
        - Ensure minimum
    - Do this to represent all LULC types and reduce variance in estimates

- Accuracy metrics 
    - Confusion matrix ==> precision, recall, F1, etc.
    - User's accuracy (precision) = If my map says the predicted area is a forest, what is the probability that it is actually a forest?
    - Producer's accuracy (recall) = Of all the forest pixels in my area, what percent did I correctly map as a forest?
    - ROC curve = map detection rate (recall) vs false alarm rate (1 - precision)
    - He also talked about F1 score

- Dynamic world
    - Model run on every sentinel2 scene that is below a certain cloud fraction
    - Individual predictions for each season is going to be noisy

## New stuff
- Thresholding
    - Seperation of foreground from background based on intensity values
    - T(x, y) = 1 if f(x, y) > T else 0 where f(x, y) is a function
    - Fixed thresholds
        - Can set manually through visual inspection
        - Use histogram to see how data is distributed
- Otsu's Thresholding Algorithm
    1. Compute histogram of image
    2. Calculate probabilities at each intensity level
    3. Initialize variables
    4. For every threshold T,
       [ w1(t) = sum of probabilities up to t
       [ w2(t) = 1 - w1(t)
    
        ... a lot more math...
    5. Select threshold w/ max in-between class variance
    - Above is the proportion of pixels in each class that you're trying out
    - Just keep like sweeping thresholds and see where you maximize variance in between the two distributions
    - This works as it assumes distribution is bimodal, it's automatic, and it's robust
